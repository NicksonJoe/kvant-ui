# Kvant — правила библиотеки

## Макет в Paper
- Источник правды — файл «Kvant — библиотека» в проекте Paper «Kvant — дизайн-система»: https://app.paper.design/file/01M7HHWM2RS5B94E91BZF6ZM5R. Адрес в коде — `PAPER_FILE_URL` в `packages/registry/meta/paper.ts`.
- В файле только переиспользуемое: токены, компоненты, нейтральные паттерны. Экраны продуктов сюда не кладутся. Норда живёт в файле «Норда — продукт» (проект «Норда»), сторонние заказы — там же или в своём проекте.
- Старый файл `01M600AT8D8Q47F7BGAQYS7J3A` теперь «Норда — продукт», библиотечных досок в нём нет. За основами и компонентами — только сюда.

## Реализовано и не реализовано
- «Реализовано» — у раздела доски есть компонент в реестре (`packages/registry/meta`, `components`). Всё остальное лежит на страницах «Не реализовано · <та же категория>».
- Раздел без кода переносится `move_nodes` на доску «Не реализовано · <имя исходной доски>». Шапка доски говорит, чего нет в коде и что из соседнего уже есть.
- Компонент реализован — его раздел переезжает обратно на доску категории «Реализовано», пустая доска «Не реализовано» удаляется. Страница «Не реализовано» без досок тоже удаляется.
- Новый макет без кода сразу кладётся на страницу «Не реализовано».

## Деструктивные действия
- Кнопка необратимого действия — только `variant="danger-soft"`: фон `--color-danger-soft`, текст `--color-danger-soft-fg`, капсула. Сплошной красной кнопки нет ни в Button, ни в макете; красный текст без фона тоже не кнопка.
- Подпись называет, что удаляется: «Удалить фото», «Удалить сделку», а не «Удалить» или «Да». В подтверждении кнопка повторяет ту же подпись.
- Исключение — свайп-действие iOS «Удалить» в строке: платформенный шаблон, остаётся сплошным.

## Как раскладывать
- Название страницы — «Раздел · Тема». Разделы: Основы, Реализовано, Не реализовано, Служебное. Они отделены разделителем, порядок страниц — как в списке выше.
- Иконки страниц: Основы — swatches, Реализовано — check, Не реализовано — cross, Служебное — padlock.
- Новая доска идёт на страницу своей категории. Новая страница — только если подходящей нет; её место и название сразу дописать сюда.
- Доска называется «Раздел · Тема[ · подтема]», ширина 1440, доски стоят в ряд по `y = 0` с шагом 1600.
- Доска компонента связана с реестром: её id — в `PAPER_BOARDS` (`packages/registry/meta/paper.ts`) и в `paperBoard` меты компонента. Перенос между страницами id сохраняет; копия в другой файл получает новые id — так не переносить.
- Токены файла и `packages/tokens` меняются вместе.
