# Kvant — ревизия и план

Дата ревизии: 16.11.2026, ветка `main` (`d8184bd`).

## Что это за проект и под какую нагрузку судили

Kvant — библиотека интерфейсов на React 19, Tailwind v4 и Base UI. Исходники 158 компонентов лежат в `packages/registry`, команда `kvant-ui` копирует их в проект потребителя, сайт `apps/docs` показывает документацию и раздаёт реестр из `apps/docs/public/r`. Макет — файл Paper «Kvant — библиотека».

Нагрузка: команду запускает один разработчик у себя; компоненты работают в браузере у многих пользователей CRM (Норда) — длинные списки, чаты с медиа, доски на сотни карточек.

## Как проверяли

- Запуском: `eslint .` — чисто; `tsc` в реестре и документации — чисто; тесты реестра 2391, CLI 20, токенов 11 — зелёные; **тесты документации — 14 падений из 259**; сборка документации проходит; пересборка токенов и реестра не даёт расхождений с закоммиченным.
- Чтением кода: CLI, токены, ~40 самых сложных компонентов, сайт документации; скриптом сверены все 158 файлов метаданных с исходниками.
- Пометка у пункта: **[запуск]** — подтверждено запуском или скриптом, **[код]** — выведено чтением кода, поведение в браузере не воспроизводилось.

Остатки после проверки «адвокатом дьявола» — не исправлялись:

- На Windows `cmd` съедает `^`, поэтому `пакет@^1.9.0` ставится как точная версия — не проверено, Windows под рукой нет.
- Проверка версии отвергает диапазоны вида `>=1.2` и `1.x || 2.x`; сборщик реестра пишет только `^x.y.z`.
- Тест экспортов видит только значения: имя типа в `source.exports` он посчитает отсутствующим.
